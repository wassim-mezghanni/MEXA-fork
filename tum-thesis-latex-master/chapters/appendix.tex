\paragraph{Hardware and compute environment.}
All embedding extractions and retrieval scoring evaluations were conducted using the COMA high-performance computing cluster and dedicated local compute nodes:
\begin{itemize}
    \item \textbf{Accelerators:} High-memory compute nodes equipped with NVIDIA H100 (96GB VRAM), NVIDIA H200 (96GB / 141GB / 144GB VRAM), and NVIDIA A100 (40GB / 80GB VRAM) GPUs managed via Slurm.
    \item \textbf{Software stack:} Python 3.10, PyTorch 2.4 with CUDA 12.4, Hugging Face \texttt{transformers} 4.44, \texttt{accelerate} 0.33, and \texttt{vLLM} 0.5.4.
    \item \textbf{Precision:} Model inference was run strictly in native \texttt{bfloat16} for causal decoders and MoE models, and \texttt{float32} for bidirectional sentence encoders to prevent numerical overflow in position-weighted hidden state pooling.
    \item \textbf{Throughput:} Total GPU computation required approximately 120 GPU-hours across all 16 architectures, 6 pivot languages, and corpus configurations.
\end{itemize}
