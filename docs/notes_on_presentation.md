# Presentation notes

- One slide (without effects) should roughly take one minute (or longer). If a slide is dense and is presented too quickly, we cannot understand the content.

Below are some suggestions for the presentation. 

- Don't hesitate to use bold fonts or colours to make keywords stand out.
- One slide per topic minimum (i.e., no slide with two different topics, such as datasets and models together; they should be separated).
- When possible, please avoid large and dense tables. Figures are nicer in a presentation (and tables in an article).
- For result slides: there should be a written takeaway about the results (roughly one sentence.
